Screen Reader

Press this button to start or stop screen capture. It starts OFF every time the plugin starts. No saved setting enables it automatically.

ON means capture is enabled. Images are captured only from the active World of Warcraft window, processed in memory and never saved or uploaded.

Keep this button and at least one Action Slot visible on the same page. Leaving that page stops capture and requires another click to restart.

Closing the game or ending its process switches the reader OFF. Starting the game again does not restart capture. Switching to another application only pauses capture while the game is still running.

OFF stops the screen reader process. Other DeckBridge functions, including keyboard actions and saved icon data, work independently.
